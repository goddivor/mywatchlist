# Decisions

Append-only, one line per decision: `- YYYY-MM-DD [unit] decision — why`. Earlier lines bind later units.

- 2026-10-27 [orchestrator] Port reference is DailyAL `upstream/2026.2.6+108` (JICA98, 2026-05-02), not the older local `psycho` branch — it holds 45 more commits (AniList sync, hide scores, status cache).
- 2026-10-27 [orchestrator] Port behaviour, never copy code: BLoC for app-wide state, Provider/ChangeNotifier user singletons, MWL service layer, multi-tracker awareness — project convention, no other state management.
- 2026-10-27 [orchestrator] MWL's current UI is not the reference: each screen takes the better of DAL and MWL and improves it; MWL-only flows (account picker) are redesigned too — owner's rule.
- 2026-10-27 [orchestrator] Builders never run `flutter build` nor touch the emulator; heavy commands go through `tools/heavy.sh` (one machine-wide flock); APK build and emulator checks belong to the checker — owner's rule on machine load.
- 2026-10-27 [orchestrator] Strings are added per unit in `lib/l10n/units/<unit-id>/` (shape fixed by `l10n-pipeline`) so parallel units never share a string file.
- 2026-10-27 [orchestrator] New dependencies and new preferences are shared shapes owned by `deps-prefs-contract`; a unit needing another one reports a finding.
- 2026-10-27 [orchestrator] Cross-unit navigation goes through `lib/utils/app_routes.dart` (owned by `app-shell`), so feature units link to each other without editing each other's files.
- 2026-10-27 [orchestrator] DAL features target MAL first; AniList/Kitsu/Simkl pages are separate later units reusing tracker-agnostic widgets. Linux tray, Windows MSIX and tablet-only polish are out of scope for now.
- 2026-10-27 [orchestrator] Tests: `test/smoke/` + `test/helpers/` owned by `gate-fix`, then `test/units/<unit-id>/` per unit; no test hits the network.
- 2026-10-27 [gate-fix] Tests are offline by construction: `test/helpers/no_network.dart` installs an `HttpOverrides` that throws `NetworkAccessInTest` on any connection, applied to every test by the root `test/flutter_test_config.dart` (a unit must not add a nested config, it would replace the root one) — "no test hits the network" is enforced, not just asked.
- 2026-10-27 [gate-fix] Shared test helpers live in `test/helpers/` (`pumpInApp` for small widgets in a bare `MaterialApp`, `htmlFixture` for offline scraper parsing); unit tests import them instead of redefining fakes.
- 2026-10-27 [gate-fix] INTERNET permission is declared in the main Android manifest, not only in the debug one, so release APKs reach the trackers.
- 2026-10-27 [auth-refresh] Every tracker token lifecycle lives in `BaseUser.sendAuthenticated`: refresh when within 60 s of expiry, one refresh + one replay on 401, transient network errors retried by `RetryPolicy` (8 attempts, backoff 250 ms doubling, cap 4 s), no other 4xx ever retried.
- 2026-10-27 [auth-refresh] A refresh answered 400/401/403 or a 401 on a tracker without refresh token (Simkl) calls `markNeedsReLogin()`: tokens dropped, status UNAUTHENTICATED, `needsReLogin` true, username and avatar kept; a network failure during refresh never logs out.
- 2026-10-27 [auth-refresh] Authenticated MAL calls use `MalConnect.authGet/authPut/authDelete` (throw `MalSessionExpired` when signed out); the Authorization header is never built by callers.
- 2026-10-27 [auth-refresh] Tests inject `BaseUser.clientFactory` and `retryPolicy` (MockClient, no sleep); a unit never needs the network.
- 2026-10-27 [backend-parsers] DailyAL page parsers live in a separate `PageParsers` class (`mwl_commons/lib/src/services/page_parsers.dart`) with typed models suffixed `Html` (`ContentCharactersHtml`, `ClubPageHtml`, `ReviewHtml`…) plus `ImageSet`, `MalNodeRef`, `MalUserRef`, `MalPath` — the 2000-line `HtmlParsers` stays untouched and the names never clash with the app's `Picture`, `ForumHtml`, `ClubStaff`, `AllSearchResult`.
- 2026-10-27 [backend-parsers] Every backend route answers `{data: …}` with JSON-ready data: `HttpConnect.htmlPage` parses on a short-lived `Isolate.run` (inline fallback on web or error) and converts models with `toJsonReady`; the app client `MwlApi` decodes bodies over 32 KB with `compute` — performance.md #9.
- 2026-10-27 [backend-parsers] `schedules` now defaults to LiveChart (DailyAL behaviour, `LiveChartEpisode`); `source=jikan` keeps the former Jikan proxy and `MwlApi.getSchedules` sends it, so no caller changes. `clubs` keeps MWL's list/search and returns the club page when `id` is given.
- 2026-10-27 [backend-parsers] Backend parser tests run in the app's `flutter test` (`test/units/backend-parsers/`) on trimmed real pages saved in `mwl-api/test/fixtures/`: mwl-api has no `test` dev-dependency (new dependencies belong to `deps-prefs-contract`) and the gate only analyzes mwl-api.
- 2026-10-27 [l10n-pipeline] ARB sources live in `lib/l10n/`: the base is DailyAL's `intl_<locale>.arb` (11 locales, orphan non-English keys dropped, `en` file tagged `en`) and is frozen; units add keys only in `lib/l10n/units/<unit-id>/intl_<locale>.arb` (English mandatory, other locales optional with English fallback) — parallel units never share a string file.
- 2026-10-27 [l10n-pipeline] `tools/l10n/build.sh` merges base + fragments and generates `S` with intl_utils (same generator as DailyAL, keeps the `S.current` API) from a separate tool package `tools/l10n/` with its own committed lock — the generator's analyzer/dart_style pins never enter the app's dependency graph; `flutter gen-l10n` is not used.
- 2026-10-27 [l10n-pipeline] `lib/generated/l10n.dart` and `lib/generated/intl/` are git-ignored build outputs; `tools/verify.sh` regenerates them first; `lib/generated/maps.dart` stays tracked (hand-written data). Anyone (CI included) must run `tools/l10n/build.sh` before analyze/test/build.
- 2026-10-27 [l10n-pipeline] Duplicate keys (base vs fragment, fragment vs fragment), translations without English, unknown locales and invalid keys fail the build — collisions between parallel units surface at the merge gate, never silently.
- 2026-10-27 [l10n-pipeline] The language is stored only in the `language_code` (ARB tag, e.g. `fr_FR`) and `use_system_language` prefs, read by `LanguageBloc` (legacy `language` key and short codes migrated on read); nothing saved means follow the device; `main.dart` applies it before `runApp` and `MaterialApp.locale` follows the bloc.
- 2026-10-27 [l10n-pipeline] A language change rebuilds the whole widget tree once (routes and state kept) because most widgets read `S.current` without an inherited dependency; pages must read strings in `build`, not cache them in `initState`.
- 2026-10-27 [l10n-pipeline] `flutter_localizations` (Flutter SDK) is declared in `pubspec.yaml`: `main.dart` imported it only transitively.
- 2026-10-27 [mal-auth-calls] Every authenticated MAL request in `mal_api.dart`, `mal_user.dart` and `mal_forum_api.dart` goes through `MalConnect.authGet/authPut/authDelete`; `MalApi._get` picks that path for a MAL account and the public client-id call otherwise, and `getHeadersForAccountType` (which built the Bearer by hand) is removed.
- 2026-10-27 [mal-auth-calls] A dead MAL session surfaces as `MalSessionExpired` from the API methods (forum methods keep returning null); list writes still throw their string when the selected account is not MAL.
- 2026-10-27 [deps-prefs-contract] Every DailyAL preference lives in `PreferencesBloc` (`lib/user/preferences/`), state `AppPreferences` in four immutable groups (`general`, `content`, `list`, `notifications`); a field changes through its group event with a `copyWith` updater (`GeneralPreferencesChanged((p) => p.copyWith(nsfw: true))`), so a new field needs no new event — one typed event per group instead of ~40 per-field events.
- 2026-10-27 [deps-prefs-contract] Code without a `BuildContext` reads `Preferences.current` (the running bloc's state, defaults before `main` created it); a background isolate reads `PreferencesStore(prefs).read()`; widgets use `context.select` on the bloc.
- 2026-10-27 [deps-prefs-contract] Each group is one JSON string in SharedPreferences (`prefs_general_v1`, `prefs_content_v1`, `prefs_list_v1`, `prefs_notifications_v1`), enums saved by name, read tolerantly field by field (bad JSON or a wrong type falls back to the default); a breaking shape change bumps the key suffix and migrates in `PreferencesStore.migrateLegacy`.
- 2026-10-27 [deps-prefs-contract] Language, theme/font/background and the home page layout stay in `LanguageBloc`, `ThemeBloc` and `HomePreferencesBloc` (not duplicated in the contract); DAL's `preferAniList` is replaced by the active tracker switch, `isRtl` derives from the language.
- 2026-10-27 [deps-prefs-contract] `TimezonePref` is declared once, in `content_preferences.dart` (re-exported by `user_preference.dart`); the legacy `timezone_pref` key is moved into `prefs_content_v1` at startup and deleted. Detail sections reuse `TabType` from `constants.dart`; saved tab lists keep their order and gain new sections (ScoreStats after Stats, as DAL).
- 2026-10-27 [deps-prefs-contract] Custom card field names come from the field type through `S` (`type.label`, `type.description`), never stored: DAL's hard-coded English titles are ignored when reading.
- 2026-10-27 [deps-prefs-contract] Dependency pins are the newest versions resolvable with Flutter 3.35.6 / Dart 3.9.2 (newer majors of flutter_local_notifications, timezone, package_info_plus, device_info_plus, add_2_calendar, build_runner need Dart 3.10+; dynamic_color 2 needs a newer material_color_utilities than the SDK pins); `json_serializable` moved to dev, `build_runner` added, third-party `flutter_localization` dropped.
- 2026-10-27 [deps-prefs-contract] Exact alarms use `SCHEDULE_EXACT_ALARM` (user-granted via `requestExactAlarmsPermission`), not `USE_EXACT_ALARM`, which store policy reserves for alarm and calendar apps.
- 2026-10-27 [deps-prefs-contract] The updater's FileProvider (`${applicationId}.fileProvider`) uses the `@xml/filepaths` resource merged from open_filex, since `android/app/src/main/res/` is not owned by any unit yet.
- 2026-10-27 [backend-parsers] A missing or invalid request parameter throws `BadRequest` (mwl_commons): the Shelf entry point answers 400 and the in-process one returns `{error: true, status: 400, message}`, never cached; `PathMatcher.intPathParam` (and `pathParam<int>`) throw it on a non-numeric segment, and `schedules` refuses an unknown `season` or a non-numeric `year` instead of using the current one (#72).
- 2026-10-27 [mal-auth-calls] With a dead MAL session (refresh refused, signed out, or 401 after a refused refresh), `MalApi.signedGet` replays a public endpoint with the client id; endpoints that need the user (path with `/users/@me`, or ending in `/suggestions`) and list writes throw `MalSessionExpired`. `MalUser` reads go through `signedGet` too.
- 2026-10-27 [mal-auth-calls] The single "MAL session expired" signal for the UI is `MalApi.sessionExpired` (`ValueListenable<bool>`, Flutter foundation, no new state library): true on the first failed call (one notification), mirrors `UserMalV2.needsReLogin`, false again after a new sign in.
- 2026-10-27 [auth-refresh] `RetryPolicy` has no per-attempt total timeout any more (#70): connect 15 s (on the `HttpClient`), response headers 30 s, body idle 30 s, so a slow but healthy large response is never cut; an overall deadline is opt-in per call (`sendAuthenticated(timeout:)`). Each attempt uses a fresh client, closed afterwards, which aborts a timed out request.
- 2026-10-27 [auth-refresh] Only GET, HEAD and OPTIONS are replayed after a transport error that may have reached the server (timeout, reset); a write (POST, PUT, PATCH, DELETE, the token refresh included) is replayed only when the error proves it was never sent (host lookup, refused, unreachable, connect timeout, TLS), unless the caller passes `idempotent: true`. The replay after a 401 is unchanged.
- 2026-10-27 [perf-foundation] Network images go through `AppImage` / `AppImage.provider` (`lib/widgets/common/app_image.dart`): `CachedNetworkImageProvider` wrapped in `SizedDecodeImage`, which picks the decoded size at decode time (cover or contain, never upscaled, rounded up to 32 px) — `memCacheWidth/Height` alone would stretch a picture whose aspect differs from its slot.
- 2026-10-27 [perf-foundation] No disk-resized copies by default (`maxDiskWidth` opt-in): flutter_cache_manager decodes twice and re-encodes PNG on first load, slower while scrolling than the decode-time resize; images show without fade (DailyAL) and with a flat placeholder unless a caller asks for a shimmer.
- 2026-10-27 [perf-foundation] Every shimmer shares one `ShimmerClock` ticker and only repaints through its render object; the clock runs only while an attached shimmer in an enabled `TickerMode` exists; the `shimmer` package is no longer used by `lib/widgets/loading/`.
- 2026-10-27 [perf-foundation] Impeller stays on, explicitly (`EnableImpeller=true` in the manifest), until the checker's A/B in `docs/PERFORMANCE.md` shows Skia (DailyAL's choice) is smoother on our gestures.
- 2026-10-27 [perf-foundation] Route transitions of `page_transitions.dart` last 250 ms with `Cubic(0.23, 1, 0.32, 1)` and the slide carries no fade (no offscreen layer over the whole page).
- 2026-10-27 [owner] The sidebar opens from a visible button: the account avatar in the home app bar (as in DailyAL); the edge swipe stays as a secondary gesture.
- 2026-10-27 [owner] A user who never picked a language gets the device language (not English).
- 2026-10-27 [owner] Help & Feedback leaves the settings hub; feedback (report a bug / open an issue) lives on the About page.
- 2026-10-27 [owner] AniList: no early warning before token expiry; when refresh fails the account goes to "sign in again" with a clear message.
- 2026-10-27 [app-shell] Cross-unit links go through `AppRoutes` static helpers (plain `MaterialPageRoute`, never `gotoPage`, which forces left-to-right); settings pages are addressed by `SettingsSection`, so a unit links to a settings page without importing it.
- 2026-10-27 [app-shell] The sidebar is the home shell's end drawer; pages reach it through `AppRoutes.openSidebar(context)` (an inherited `HomeShell`, no global key), outside the shell it is pushed as a page.
- 2026-10-27 [app-shell] Home tabs: no animated opacity on tab switch; only the current tab is built unless `keepPagesInMemory`, in which case tabs are built on first visit and kept in an `IndexedStack`; the shell rebuilds only when the selected tracker changes (`BlocSelector`).
- 2026-10-27 [app-shell] "Session expired" is read from `UserManager.trackersNeedingReLogin` (BaseUser `needsReLogin`, every tracker), shown once per tracker as a floating snackbar and as a card in the sidebar; "Sign in" restarts the tracker's OAuth flow (Kitsu opens the tracker manager).
- 2026-10-27 [app-shell] Notification payloads are plain strings `anime:<malId>`, `manga:<malId>`, `calendar`, `bookmarks` (`NotificationRoute`), routed by the home shell after its first frame via `HomeScreen/OpenScreen(notificationPayload:)`.
- 2026-10-27 [app-shell] Startup pages that are not tabs (calendar, search) open on top of the home tab.
- 2026-10-27 [app-shell] System Back in the home shell goes through one `PopScope` (`ShellBackScope`): sidebar open → close it; other tab → home tab (DAL); home tab → "Press Back again to exit" for 2 s, then the app may close. A Scaffold drawer alone never tells Android that Flutter handles Back, so with predictive back (targetSdk 36) the system closed the app; the scope's `canPop` keeps the platform informed. The double Back on the home tab guards against an edge swipe meant for the sidebar landing in the system back zone (MWL addition, DAL exits at once).
- 2026-10-27 [shared-kit] Select widgets are generic and controlled: options are `SelectOption<T>(value, translated label, icon?)`, the caller keeps the selected value; `showSelectSheet` switches to the searchable sheet above 15 options — one shape for every picker instead of DAL's parallel `options`/`displayValues` string lists.
- 2026-10-27 [shared-kit] `AppBarMenu` holds no feature logic: a standard slot (share, open in browser, bookmark) appears only when its callback is given and the menu renders nothing when empty — no dead buttons.
- 2026-10-27 [shared-kit] Links open through `lib/utils/web_launcher.dart`: Custom Tabs / Safari view themed with the surface colors, system browser fallback; MyAnimeList links go to `WebLauncher.internalLinkHandler` first (registered by `deep-links` from `lib/utils/deep_links.dart`) and open their in-app screen without the confirmation dialog; `launchURL`/`launchURLWithConfirmation` in `constants.dart` keep their signatures and delegate.

- 2026-10-27 [shared-kit] `gotoPage` no longer wraps pushed pages in a left-to-right `Directionality`, so pushed pages follow the app language (Arabic right-to-left).
- 2026-10-27 [shared-kit] Kit strings use the `Kit_` key prefix; API dates are formatted by `formatApiDate` without intl (`yyyy-MM-dd` whatever the locale), display dates by `DateFormat.yMMMd` of the app locale.
- 2026-10-27 [shared-kit] `loadingText` and `loadingGraph` in `constants.dart` use `ShimmerColor` (one shared ticker after perf-foundation) instead of their own `Shimmer.fromColors`; `constants.dart` no longer imports `shimmer`.
- 2026-10-27 [detail-split] The detail screen lives in `lib/screens/MAL/detail/` (`contentdetailedscreen.dart` is a re-export): `DetailData` is one immutable snapshot (MAL details, scraped page, videos, load state) replaced by `copyWith` on each answer, with the scraped lists parsed once per snapshot; sections, header and actions only read it.
- 2026-10-27 [detail-split] Sections come from `DetailSections.registry` (`TabType` → `DetailSection? Function(DetailData)`, one file per section in `detail/sections/`), walked in the order of `ContentPreferences.visibleTabs`; the open screen listens to `Preferences.bloc` and rebuilds its sections when that order changes — a new section is a registry line, never a screen edit. Manga pages therefore follow DAL's manga defaults (no Media, Stats or Score stats).
- 2026-10-27 [detail-split] Detail scroll: one listener added in `initState` and removed in `dispose`; the app-bar title follows a `ValueNotifier` updated only when the scroll direction flips; the tab is synced at most once per frame after a 24 px move, never during a tab-tap scroll, and only when the centred section changes; a replaced `TabController` is disposed after the next frame; section `GlobalKey`s are kept per `TabType` so sections keep their state when data arrives.
- 2026-10-27 [detail-split] App bar actions are `buildDetailActions` in `detail/actions/` (search works; share, open in browser, bookmark and overflow menu are documented `null` extension points for `detail-header`); the cover info button opens `showMoreInfoModal`. A failed MAL load shows `DetailErrorView` with retry (session-expired wording on `MalSessionExpired`) instead of an endless shimmer.
- 2026-10-27 [edit-sheet] The edit sheet fetches its own `GET /anime|manga/{id}?fields=…my_list_status{…}` through `MalApi.authorizedGet` instead of reading `MalAnime.myListStatus`, whose model keeps only status, score, episodes and rewatching; dates stay MAL's text so partial dates (`2019-03`) are shown and kept exactly.
- 2026-10-27 [edit-sheet] Auto dates (pref `autoAddStartEndDate`) only fill an empty date, never overwrite: watching/reading or the first progress fills the start date, completing (by status or by reaching the known total) fills the finish date; a planned entry that gets progress becomes watching/reading, as on MAL's site.
- 2026-10-27 [edit-sheet] Private notes live in `PrivateNotesStore` (one SharedPreferences string per entry, key `private_note_v1:<tracker>:<category>:<id>`, blank = removed); `export()` gives `{version: 1, notes: {"mal:anime:5114": text}}` and `import(data, replace:)` restores it for the backup unit.
- 2026-10-27 [edit-sheet] Sheet labels whose base French is wrong (`Rewatching` = « Rétablissement », `Times_Rewatched`, lowercase `Comments`/`Save`, English status map) use `Edit_*` keys of the unit fragment; the base ARBs stay frozen.
- 2026-10-27 [edit-sheet] The episode picker mode (bar or number field) is kept in memory for the session only: persisting it would need a new preference, owned by the preferences contract.
- 2026-10-27 [api-prefs] Every Jikan call goes through `JikanClient.instance.get` (`lib/services/api/Jikan/jikan_client.dart`): requests spaced by 350 ms on one queue, identical in-flight requests shared, 200 answers cached 5 min (150 entries), a 429 retried up to 3 times (`Retry-After`, else 1/2/4 s capped at 8 s) with the whole queue paused; after the retries the 429 response reaches the caller.
- 2026-10-27 [api-prefs] `MalApi.withNsfw` adds `nsfw=1|0` from `Preferences.general.nsfw` to every MAL GET (signed and public) unless the URL already carries `nsfw`; airing time helpers default to `Preferences.content.timezone` when no pref is passed, and the schedule weekday follows that time zone.
