## Where we are (2026-10-27)
- Porting every DailyAL feature (ref `upstream/2026.2.6+108`) into MWL, adapted to BLoC + multi-tracker, redesigning weak UI and fixing bugs on the way. ## AniList pages (`anilist-pages`)
- Five tabs (`lib/pages/Anilist/`): home (chips, sections of the shared `HomePreferencesBloc`: season, trending, rankings, user list, forum; news/features skipped), explore (search, anime/manga rows via `AsyncSection`, genres), user list (`UserListView` + `AnilistUserListAdapter`: whole list in one request kept 1 min, status/sort on the device, edit through `showTrackerEntryEditor`, +1/-1 through `TrackerSyncService`), profile (shared `ProfileHeader`, stats charts, about, favorites), forum (threads by sort, open on anilist.co). Services (`lib/services/api/Anilist/`): `AnilistGraphql` (public or `sendAuthenticated`, `AnilistSessionExpired`), `AnilistListService` (entries to `ListEntryView`, `malId` = `idMal`, `airingCandidates()` for notifications), `AnilistDiscoverService`, `AnilistProfileService`. Titles without `idMal` open on anilist.co. Strings `Al_*`. Client limits (`anilist-client-limits`): every request takes a token of `AnilistRateLimiter.shared` (30/min, follows `X-RateLimit-*`, a 429 pauses all for `Retry-After`; reads retry once, else `AnilistRateLimited` + `Anilist_Rate_Limited`); writes through `mutate()` (not idempotent), several reads in one request through `batch({alias: field}, variables: {n: GqlVar(type, v)})` → `AnilistBatch`; `AnilistMedia.fields` asks `weightedScore` (`scoreOf` falls back on `averageScore`); `AnilistActions.instance.toggleFavourite/toggleLike (ToggleLikeV2)/toggleFollow`.
## Kitsu pages (`kitsu-pages`)
- Tabs `lib/pages/Kitsu/`: home (trending row + the shared `HomePreferencesBloc` sections Kitsu can fill; news/suggested/features/forum skipped), explore (search screen, anime/manga rows, categories, `KitsuBrowseScreen` grids), user list (`UserListView` + `KitsuUserListAdapter`: paged 200, only "last updated" sorted by Kitsu, rest on the device, edit through `showTrackerEntryEditor`, +1/-1 with the MAL progress rules), profile (`KitsuProfileView`: stats by status, time, categories, About, Favorites), forum = message + link. `lib/services/api/Kitsu/`: `KitsuHttp` (public or `sendAuthenticated`, `KitsuSessionExpired`), `KitsuCatalog`, `KitsuLibrary` (`airingCandidates()` for notifications), `KitsuProfiles`. `include=mappings` gives `malId` (a card opens the MAL detail; none = snackbar). Strings `Kitsu_*`. Simkl pages are still placeholders. `SimklClient` (`lib/services/api/SimKl/simkl_client.dart`): every call sends `app-name`, `app-version` (query and headers) and `User-Agent: MyWatchList/<version>` (version from `package_info_plus`); reads `X-RateLimit-Remaining` into `rateLimitRemaining`; a 429 throws `SimklRateLimited` (a `SimklHttpError` 429, `retryAfter`) and pauses the client without network until `Retry-After` (else 15 s doubling, max 10 min). Simkl auth (`simkl-auth-v2`): AUTH V2 (`SimklOAuth2` in `simkl_auth.dart`: `/oauth2/authorize` PKCE S256, scopes `media:read media:write`, `/oauth2/token` code + refresh, `/oauth2/revoke` on sign out) once `SIMKL_V2_CLIENT_ID` is in `assets/.env`, else V1; V1 sessions keep working side by side (token prefix `simkl_at_` = V2), `UserSimklV2.apiClientId` is the client id of the session, `canUpgradeToV2` flags a V1 session. `simkl_api.dart` (search with the token when signed in) and `SimklEntryClient` go through `SimklClient` (`SimklApi.sessionClient`); `SimklClient.instance` still sends the V1 id (finding).
- `KitsuGraphql` (`lib/services/api/Kitsu/kitsu_graphql.dart`, `kitsu-graphql`, read-only, `instance` replaceable): `POST kitsu.io/api/graphql`, anonymous or `auth: true` via `sendAuthenticated`; typed `mediaDetail` (one request: ranks, streaming, episodes/chapters, relations, reactions, posts, cast, staff, categories, mappings), paged connections with `KitsuPageArgs`/`KitsuConnection.nextPage`, `post` thread, `profile*` (activity, reactions, posts, followers, favourites, library), `lookupMapping`; feeds, groups and `ratingFrequencies` go through JSON:API (not in the schema). Partial errors keep data (null nodes skipped). Forum tab (`kitsu-community`): `KitsuForumPage` = Latest (global feed) / News (group 596) / Groups, `KitsuGroupScreen`, `KitsuPostPage` (thread), `KitsuMediaDiscussionPage` (`widgets/Kitsu/feed/`, for the title page); paging in `KitsuFeedController` (`kitsu_feed.dart`, posts only, deduplicated; `KitsuFeed.newsPosts` feeds the home News row); strings `Kc_*`.
